Kurz erklärt

Noch etwas offen?

Brauche ich eine Anmeldung?

Die fünf eingebauten Starter-Cosmetics funktionieren ohne Anmeldung. Gemeinsame Link-Funktionen brauchen eine Verbindung zum Link-Server; zusätzliche Cosmetics können eine Freischaltung voraussetzen.

Kann ich eigene Cosmetics verwenden?

Ja. Lege .fumbovoxel-Dateien unter config/fumboclient/cosmetics/models/ ab. Der Cosmetic Builder ist ein separater Editor. Ein öffentlicher Editor-Download ist auf dieser Website noch nicht verfügbar.

Wie funktionieren Creator-Codes?

Öffne in der Garderobe „Creator-Code“ und löse einen verfügbaren Code ein. Dafür muss die Link-Verbindung aktiv sein. Die Codes und Belohnungen verwaltet der Server-Owner.

Kann ich den Client auf jedem Server nutzen?

Die verfügbaren Helfer hängen vom Server ab. Freunde, Gruppen und gemeinsame Cosmetics benötigen ein passend eingerichtetes Link-Backend. Beachte die Regeln des jeweiligen Servers.
