FUMBO STUDIO

Deine Ideen brauchen keine Vorlage.

Eigene Blockmodelle im separaten Cosmetic Builder erstellen und als .fumbovoxel speichern. Zum Bearbeiten ist kein Minecraft nötig. Ein öffentlicher Editor-Link ist hier noch nicht verfügbar.

IN WENIGEN SCHRITTEN

Startklar machen.

Kein eigener Launcher nötig.
Dein Fabric-Profil reicht.

  1. 01

    Fabric vorbereiten

    Installiere Fabric Loader für die gewünschte Minecraft-Version. Ergänze die dazu passende Fabric API im mods-Ordner deines Profils.

  2. 02

    Client einsetzen

    Minecraft schließen, die passende FumboClient-JAR herunterladen und in denselben mods-Ordner legen. Beim Update die alte FumboClient- bzw. hugosmp-lite-JAR entfernen.

  3. 03

    Spielen. H drücken. Loslegen.

    Starte dein Fabric-Profil. Öffne in Minecraft mit H das Client-Menü. Die kostenlosen Starter-Cosmetics findest du in der Garderobe; für gemeinsame Link-Funktionen brauchst du eine Verbindung zum Link-Server.

GUT ZU WISSEN

Kurz beantwortet.

Ist FumboClient ein eigener Launcher?

Nein. FumboClient ist eine clientseitige Fabric-Mod. Du nutzt weiterhin deinen gewohnten Minecraft-Launcher mit einem passenden Fabric-Profil.

Brauche ich für Cosmetics eine Anmeldung?

Die fünf eingebauten Starter-Cosmetics funktionieren ohne Anmeldung oder Link-Schlüssel. Zusätzliche Server-Cosmetics können eine Link-Verbindung und eine Freischaltung voraussetzen.

Wie verwende ich ein eigenes Blockmodell?

Exportiere es im Editor als .fumbovoxel und lege die Datei unter config/fumboclient/cosmetics/models/ ab. Die serverweite Veröffentlichung übernimmt der Owner über die geschützte Serververwaltung.

Funktioniert alles auf jedem Server?

Die verfügbaren Helfer hängen vom Server ab. Freunde, Gruppen und gemeinsame Cosmetics benötigen ein passend eingerichtetes Link-Backend. Beachte immer die Regeln des jeweiligen Servers.

Wo finde ich neue Versionen?

Alle veröffentlichten Versionen findest du auf GitHub Releases. Im Spiel kannst du unter H → Einstellungen → Updates manuell nach Updates suchen.
